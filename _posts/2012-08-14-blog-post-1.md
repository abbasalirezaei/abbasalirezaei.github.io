فرض کنید یکی از کارمندهای شرکت قراره چند روز سفر کاری بره و قراره با لپتاپ شخصی خودش کار کنه، نه لپتاپ شرکت. مشکل اینجاست که نمیخواید دیتای شرکت روی هارد یه سیستم شخصی و خارج از کنترل IT ذخیره بشه.

اینجا دقیقاً یکی از سناریوهایی بود که **Windows To Go** براش طراحی شده بود.

## Windows To Go چی بود؟

Windows To Go این امکان رو فراهم میکرد که یک **Windows Workspace** کامل و قابل مدیریت رو روی یک USB Drive سازگار قرار بدید — با اپها و تنظیمات مخصوص سازمان — و Windows رو مستقیماً از روی همون USB اجرا کنید، بدون اینکه لازم باشه چیزی روی هارد سیستم نصب بشه.

## یک مثال واقعی

کارمند با لپتاپ شخصیاش میره سفر. USB شرکت رو وصل میکنه، سیستم رو از روش بوت میکنه و وارد یک محیط Windows کامل و ازقبلآمادهشده میشه؛ همون Windows سازمانی، با همون اپها و پالیسیهای امنیتی.

کارش که تموم شد، USB رو درمیاره و روی هارد سیستم شخصیش **هیچ اثری از دیتای شرکت باقی نمیمونه**.

## کاربرد در IT داخلی

از این قابلیت توی سناریوهای IT داخلی هم استفاده میشد. مثلاً وقتی یکی از سیستمهای کاربران به دلیل یک مشکل نرمافزاری دیگه بهدرستی Boot نمیشد، تکنسین میتونست:

1. سیستم رو از روی USB خودش بوت کنه
2. وارد یک محیط Windows آماده بشه
3. قبل از اینکه سراغ نصب مجدد بره، ابزارهای موردنیاز رو برای بررسی دیسک، فایلها، شبکه و مشکلات سیستم اجرا کنه

## مقایسه با Live USB لینوکس

اگه با Linux کار کرده باشید، احتمالاً این مفهوم براتون آشناست:
Live USB یعنی:
USB → Boot → اجرای سیستمعامل بدون نصب روی هارد

Windows To Go هم از نظر ایده کلی شبیه Live USB لینوکس بود، اما دقیقاً یک فناوری یکسان نبود:

| ویژگی | Live USB لینوکس | Windows To Go |
|--------|------------------|----------------|
| هدف اصلی | استفاده موقت، تست، نصب، عیبیابی | محیط کامل و قابل مدیریت Windows |
| سناریو | شخصی و فنی | سازمانی |
| ماندگاری | معمولاً موقت | دائمی و قابل مدیریت |

## محدودیتها و پایان راه

البته Windows To Go محدودیتهایی هم داشت:

- ❌ نیاز به USBهای سازگار خاص
- ❌ عدم پشتیبانی از Feature Updateهای Windows
- ❌ الزامات سختافزاری جدید مثل TPM 2.0
- ❌ تغییر مسیر مایکروسافت به سمت راهکارهای کلاودی مثل Windows 365

در نهایت **Microsoft توسعه Windows To Go رو متوقف کرد** و این قابلیت از **Windows 10 version 2004** به بعد دیگه ارائه نشد.

## امروز چه گزینهای داریم؟

**سؤال:** امروز اگه بخوایم یک Windows رو از روی USB بوت کنیم — مثلاً برای تعمیر یا نصب سیستم — چه گزینهای داریم؟

**جواب:** یکی از جوابها **WinPE (Windows Preinstallation Environment)** هست؛ با این تفاوت که:

- WinPE یک محیط **سبک و مینیمال** برای عیبیابی و نصبه
- نه یک Windows کامل با اپ و پروفایل کاربر مثل Windows To Go

در پستهای بعدی میتونیم بیشتر راجع به WinPE صحبت کنیم.
